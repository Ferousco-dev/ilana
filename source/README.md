# SOURCE MATERIAL

`SEN102-212-Software-Engineering-Process.pdf`

The complete lecture deck for **SEN102/212 Software Engineering Process**, Department of Software
Engineering, Obafemi Awolowo University, Ile-Ife. 362 pages.

Included here so that anyone using Ìlànà can check the primary text, and so that the material it is
built on is properly attributed rather than silently absorbed.

---

## Contents

| Section | Lecturer | Topics |
| --- | --- | --- |
| Requirements, design, interface, coding, testing, SCM | Dr (Mrs) Onifade M. T. | requirements engineering and its five stages, three requirement types, six challenges and strategies; software design and its three levels; user interface design and the five principles; coding standards and guidelines; four testing levels, test planning, automation, defect tracking; software configuration management, Git, change, build and release management |
| Process modeling and documentation; tools | F. C. Ugwu | process modeling, UML activity diagrams, BPMN, documentation standards and types, process workflows; CASE tools, project management tools (Jira, Trello), continuous integration tools |
| Quality assurance; process assessment; ethics and teams | Ubochi Chibueze Nmamouh | software quality assurance and its five core activities, quality attributes, metrics; process assessment, CMMI, ISO/IEC 12207, process optimization; process ethics, ACM/IEEE code, team dynamics, Agile, DevOps, plan-driven approaches |

The deck also contains extensive self-assessment question banks, which informed the assessment banks
in `skill/interrogation/banks/`.
