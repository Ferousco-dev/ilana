# INSTRUMENT: CMMI PROBE

An indicative self-assessment. **Not a formal SEI appraisal**, and Ìlànà says so on every page that
carries a level.

## Probe questions, by level

Answer each with evidence. A "yes" without evidence is a "no".

### Level 2 (Managed): is work planned and tracked?

- [ ] Is there a plan for this project that predates the work?
- [ ] Is progress tracked against it?
- [ ] Are requirements managed, with changes going through a controlled process?
- [ ] Are commitments made and revised deliberately rather than silently?
- [ ] Does the project survive the absence of any one individual?

If success depends on individual heroics, this is **level 1**, whatever the documentation says.

### Level 3 (Defined): is there one organisational process?

- [ ] Is there a **standard organisational process** that projects tailor from?
- [ ] Do different projects in this organisation follow recognisably the same process?
- [ ] Is training provided so people know the process?
- [ ] Are the process assets maintained by someone whose job that is?

**The boundary:** per-project documented practice is still level 2. Level 3 requires
standardisation **across the organisation**. This is the distinction most self-assessments get
wrong in their own favour.

### Level 4 (Quantitatively Managed): is performance controlled statistically?

- [ ] Are process performance measures collected consistently?
- [ ] Is there a baseline for what normal performance looks like?
- [ ] Are decisions made from that data rather than from judgement?
- [ ] Can you predict outcomes quantitatively rather than by feel?
- [ ] Is variation understood, so an unusual result is recognised as unusual?

**The boundary:** excellent documented, standardised processes with no quantitative control is
**level 3**. The transition requires beginning to manage, measure and control process performance
using quantitative data and statistical techniques.

### Level 5 (Optimizing): does the process improve itself?

- [ ] Are processes continuously refined based on performance data and feedback?
- [ ] Is innovation deliberately introduced and evaluated?
- [ ] Are problems prevented before they occur, rather than fixed after?
- [ ] Can you name a process change made in the last quarter **because the data said so**?

## Scoring

| Evidence | Indicative level |
| --- | --- |
| Work is ad hoc, chaotic, dependent on individual effort, results unpredictable | 1 Initial |
| Work is planned and tracked, basic project management present, requirements managed | 2 Managed |
| One documented, standardised organisational process, training provided, consistently followed | 3 Defined |
| Quantitative and statistical control of process performance | 4 Quantitatively Managed |
| Continuous refinement driven by performance data; problems prevented before occurring | 5 Optimizing |

## Reporting rules

1. Always say **indicative**.
2. Always show the evidence behind the level.
3. Always explain the boundary: why this level and not the next.
4. Never state a level as an achievement or a certification.
5. Report the gap that blocks the next level as a concrete, small action, not as a programme.

## The common self-assessment errors

| Error | Correction |
| --- | --- |
| Claiming 3 on per-project documentation | 3 requires organisational standardisation |
| Claiming 4 on having dashboards | 4 requires decisions made from statistical understanding of variation |
| Claiming 5 on holding retrospectives | 5 requires retrospectives that demonstrably change the process |
| Claiming any level as a certification | levels are awarded by certified appraisers, not by self-assessment |
