# PHASE 04 QUESTIONS

Maximum five. Most of what you need is already in the design.

1. Does this project already have a coding standard, a linter config, or a formatter config?
   (Check the repository before asking. Asking for what you can read is a process failure.)
2. What language and runtime versions must this support?
3. Are there existing modules I should extend rather than new ones I should create?
4. What is the review process: who approves, and is approval required to merge?
5. Where do configuration and secrets come from in each environment?

## Ask when the codebase is unfamiliar

6. Which part of this codebase is the team most afraid to change, and why?
   (That is where the real constraints are.)
7. Is there a module whose conventions I should mirror as the local house style?
