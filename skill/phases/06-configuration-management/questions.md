# PHASE 06 QUESTIONS

Maximum five. Check the repository first for anything answerable there.

1. What is the branching strategy today, and is it written down anywhere?
2. How does a change get from a developer's machine into production? List every step, including
   the manual ones.
3. Can you rebuild the production environment from source, from scratch, with nobody
   remembering a step? If not, which step lives only in someone's head?
4. When something goes wrong in production, what is the rollback, and when was it last performed?
5. Who is allowed to approve a release, and is that recorded?

## Ask for regulated contexts

6. Who authorises a change, and is that authorisation auditable?
7. How long must release evidence be retained?

## Ask when there is a support obligation

8. How many versions are supported simultaneously, and how do fixes reach the older ones?
