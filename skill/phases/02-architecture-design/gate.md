# PHASE 02 GATE

Full criteria: `gates/G2-design.md`.

Quick form for `RIGOUR` 1 to 2:

1. Components named, with responsibilities.
2. Every requirement maps to something; nothing is designed that no requirement asked for.
3. Every NFR has a mechanism.
4. One alternative was considered and rejected in writing.

At `RIGOUR` 1, the whole design document may reasonably be one page and a diagram. It still has
to exist, because the alternative is that it exists only in one person's head.
