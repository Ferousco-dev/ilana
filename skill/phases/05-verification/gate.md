# PHASE 05 GATE

Full criteria: `gates/G5-verification.md`.

Quick form for `RIGOUR` 1 to 2:

1. Tests exist and pass, with counts stated.
2. Every requirement has at least one test.
3. Failure paths are tested, not only success paths.
4. Open defects are listed with severity.

Report the actual numbers. "Tests pass" is an assertion; "61 tests, 61 passed, 0 failed, 0
skipped" is evidence. Article 2 applies here more than anywhere.
