# PHASE 03 GATE

Full criteria: `gates/G3-interface.md`.

Quick form for `RIGOUR` 1 to 2:

1. The five principles have each been considered, in one sentence each, against the real screens
   or commands.
2. Every error has a message that says what to do next.
3. Every destructive action has undo or confirmation.

If the system genuinely has no human interface (a library, a pure batch job), record that and
skip the phase. Record it; do not silently skip it, because "no human interface" is usually
wrong and the check is what catches it.
