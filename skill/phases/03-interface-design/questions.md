# PHASE 03 QUESTIONS

Maximum five.

1. Who operates this, how often, and under what conditions? (An interface used once a year by
   a stressed person is a different design from one used 200 times a day by an expert.)
2. What is the single most frequent task? Everything else is secondary to making that one fast.
3. What is the most dangerous action available, and what happens if it is taken by accident?
4. Is the user interrupted while using this? (Interruptible tasks need resumable state.)
5. What device, screen, and environment? Bright sunlight, gloves, one hand, a shared terminal,
   a screen reader.

## Ask for CLIs specifically

6. Will this be scripted? If yes, output must be machine-parseable and exit codes meaningful.
7. Is it run interactively, in CI, or both? Colour and progress behaviour differ.

## Ask when replacing an existing interface

8. What muscle memory exists today that we would be destroying?
