# PHASE 08 QUESTIONS

Maximum five.

1. What data already exists? Commit history, CI runs, defect tracker, monitoring, review
   comments, time tracking. (Absence is itself the finding.)
2. What process change did you make last time, and did it work? Name the metric that shows it.
3. Where does work actually stall? Not where it feels slow, where it measurably waits.
4. What fraction of effort is rework: work repeated because of an error or a change?
5. If you could change exactly one thing about how this team builds software, what would it be?
   (Ask the team, not the manager. Then compare with what the data says.)

## Ask when assessing maturity

6. Is there one organisational process that projects tailor from, or does each project invent
   its own? (This is the level 2 to 3 boundary.)
7. Are any decisions currently made from statistics rather than judgement? (Level 3 to 4.)
8. When did the process last change because data said it should? (Level 5.)
