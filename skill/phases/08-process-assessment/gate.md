# PHASE 08 GATE

Full criteria: `gates/G8-closure.md`.

Quick form for `RIGOUR` 1 to 2:

1. One number exists that describes how this run went.
2. One thing the process caught is named.
3. One thing the process missed is named, with the gate that should have caught it.
4. One change goes into the next run, with an owner.

Four sentences is a legitimate retrospective at low rigour. Zero sentences is not, because then
the next run repeats this run exactly.
