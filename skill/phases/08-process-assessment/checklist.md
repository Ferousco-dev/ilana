# PHASE 08 CHECKLIST

## Measurement
- [ ] Process metrics collected, not estimated
- [ ] Defect rate recorded over a defined period
- [ ] Time to complete representative tasks recorded
- [ ] Rework effort quantified
- [ ] Every metric has a named source
- [ ] Estimates are labelled as estimates

## Assessment
- [ ] Each of the eleven phases assessed for evidence of practice
- [ ] Indicative CMMI level derived, with the evidence behind it
- [ ] The level 3 to 4 boundary applied correctly (quantitative control, not just documentation)
- [ ] The word "indicative" used; no claim of formal appraisal

## ISO/IEC 12207 mapping
- [ ] Primary processes mapped to actual activities
- [ ] Supporting processes mapped
- [ ] Organizational processes mapped
- [ ] Gaps identified: processes the standard names that the team does not perform

## Improvement
- [ ] Weaknesses identified from data, not from opinion
- [ ] Exactly one improvement selected for the next cycle (not five)
- [ ] The improvement has an owner and a start date
- [ ] A success metric is defined with a baseline and a target
- [ ] A recheck date is set

## Optimization
- [ ] Automation opportunities identified with the hours they would save
- [ ] Best practices adopted are named, not gestured at
- [ ] Monitoring and feedback loops exist and are used
- [ ] Metrics actually inform decisions

## Retrospective
- [ ] What the process caught is quantified
- [ ] What the process missed is quantified, with the gate that should have caught it
- [ ] Ceremony that produced no finding is identified for trimming
- [ ] Prevention ratio calculated and compared to the previous run
