# PHASE 09 GATE

This phase is continuous and has no dedicated gate. It is checked inside G7 and G8.

- **G7** checks that documentation standards are named and followed.
- **G8** applies the onboarding test: could a new engineer operate this system from the
  documentation alone?

At `RIGOUR` 1 to 2 the requirement collapses to: a README that lets someone build, run and test
the project, and one diagram of how the pieces fit together. That minimum is not negotiable,
because it is the difference between a project and a personal artifact.
