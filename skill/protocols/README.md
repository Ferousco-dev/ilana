# PROTOCOLS

Repeatable procedures that cross phases. Load one when you are about to perform it, not before.

| Protocol | Use when |
| --- | --- |
| `question-engine.md` | any time Ìlànà needs to ask the user something |
| `elicitation.md` | gathering requirements from humans |
| `review-inspection.md` | running a walkthrough, an inspection, or a peer review |
| `defect-lifecycle.md` | a defect is found, triaged, fixed or closed |
| `change-control.md` | anything about the agreed scope is changing |
| `conflict-resolution.md` | two people or two requirements disagree |
| `escalation.md` | blocked, or a gate has failed twice |
| `release.md` | shipping |
| `incident.md` | something is broken in production |
| `handoff.md` | moving work between agents or phases |
