Run Ìlànà in `DRILL` mode. Read `~/.claude/skills/ilana/SKILL.md`, `modes/drill.md` and
`assessments/README.md`.

Format requested: $ARGUMENTS (default: `rapid` if not specified)

| Format | Shape |
| --- | --- |
| `rapid` | 10 multiple choice, mixed phases |
| `phase <n>` | 15 questions confined to one phase, increasing difficulty |
| `scenario` | 5 case scenarios requiring judgement and justification |
| `viva` | open-ended, adaptive, follow-up on every answer |
| `ethics` | dilemmas only, from phase 11 |
| `gauntlet` | 40 questions across all eleven phases, full scorecard |

Draw questions from `interrogation/banks/`. Use the scenario bank at `interrogation/banks/scenarios.md`
for applied formats.

**Marking rules, which matter more than the questions:**

1. **Mark honestly.** A wrong answer is wrong. Never soften it into "close".
2. **Give the distinguishing test, not the letter.** If they confused walkthrough with inspection,
   the answer is "author-led and informal versus Moderator, Reader and Recorder with strict
   procedure", not "the answer was C".
3. **Attribute every miss to a phase.** Errors cluster, and the cluster is the actual finding.
4. **Never reveal the answer inside the question.**
5. Scenario answers get the five-point rubric from `assessments/README.md`, not a binary mark.

Ask the questions in batches, not one at a time. End with the scorecard by phase, and **three
specific next actions**, each naming a file to read.
